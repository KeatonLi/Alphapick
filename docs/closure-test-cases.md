# AlphaPick 闭环测试用例

## 目标

验证系统主线是否闭环：交易日识别 -> 每日推荐 -> 收益跟踪 -> 策略复盘 -> 页面展示。

## 后端闭环用例

1. 非交易日调度跳过
   - 输入：模拟休市日。
   - 执行：运行 scheduler 日任务。
   - 期望：不采集、不生成推荐，任务结果明确标记为非交易日跳过。
   - 覆盖：`backend/tests/test_scheduler_workflow.py`。

2. SQLite 推荐收益闭环
   - 输入：SQLite 内存库，构造某交易日 3 只推荐股票和后续行情。
   - 执行：生成推荐记录，再触发收益更新。
   - 期望：推荐记录写入成功，第 3 天收益被计算并落库。
   - 覆盖：`backend/tests/test_sqlite_quant_flow.py`。

3. 推荐批量更新
   - 输入：重复股票、异常股票、有效股票混合批次。
   - 执行：批量更新推荐记录。
   - 期望：重复项去重，异常项返回错误，有效项正常落库。
   - 覆盖：`backend/tests/test_recommend_batch_update.py`。

4. 涨停池真实结构解析
   - 输入：`raw_data_records` 中的 `limit_up_pool` 原始结构。
   - 执行：调用涨停池服务解析。
   - 期望：股票代码、连板数、行业、封板强度、成交额等字段正确输出。
   - 覆盖：`backend/tests/test_limit_up_service.py`。

## 前端页面用例

1. 登录入口
   - 执行：游客登录。
   - 期望：进入推荐工作台。
   - 覆盖：`frontend/scripts/smoke-pages.mjs`。

2. 推荐工作台
   - 执行：加载推荐页。
   - 期望：显示推荐股票、中文因子、交易日选择器；普通用户不展示手动更新收益按钮。
   - 覆盖：`frontend/scripts/smoke-pages.mjs`。

3. 用户中心
   - 执行：进入用户中心。
   - 期望：显示会员状态、账号信息、联系管理员开通会员入口。
   - 覆盖：`frontend/scripts/smoke-pages.mjs`。

4. 涨停板分析
   - 执行：加载涨停板页面。
   - 期望：按 4板、3板、2板、首板分组展示，使用表格化布局，而不是长列表。
   - 覆盖：`frontend/scripts/smoke-pages.mjs`。

## 人工验收清单

1. 打开 `http://127.0.0.1:5174/`，游客登录。
2. 推荐工作台默认展示最近交易日，而不是自然日休市日。
3. 切换交易日后，推荐股票和收益跟踪同步变化。
4. 涨停板分析中，高位连板和首板分区清晰可扫读。
5. 用户中心能说明当前是否会员，以及如何开通会员。
