# 市场情绪仪表盘设计方案

> 日期：2026-05-25 | 状态：已批准

---

## 一、目标

在「每日量化报告」旁边新增一个「市场情绪」独立 Tab，展示当日市场情绪指标，辅助判断市场冷热。

---

## 二、数据内容

| 指标 | 数据来源 | 说明 |
|------|---------|------|
| 上涨/下跌/平盘家数 | `ak.stock_zh_a_spot()` | 实时全市场统计 |
| 涨停/跌停数 | `ak.stock_zh_a_spot()` | 涨跌幅 >= 9.5% / <= -9.5% |
| 昨日涨停股今日表现 | `market_reports.yesterday_limit_ups` | 昨天涨停股今天的平均涨跌幅 |
| 市场温度计 | 派生指标 | 根据上涨家数/总家数比例，0-100 评分 |

### 市场温度计计算规则
```
上涨比例 = 上涨家数 / (上涨 + 下跌 + 平盘)
温度分 = 上涨比例 * 100，截断到 [0, 100]
```
| 分值 | 情绪标签 |
|------|---------|
| 0-30 | 🧊 冰点（恐慌） |
| 30-50 | ❄ 冷淡 |
| 50-65 | 🌤 平稳 |
| 65-80 | 🔥 活跃 |
| 80-100 | 🤯 狂热 |

---

## 三、数据库改动

### market_reports 表新增字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `yesterday_limit_ups` | TEXT (JSON) | 昨日涨停股代码列表 |
| `yesterday_limit_ups_performance` | DECIMAL(5,2) | 昨日涨停股今日平均涨幅（%） |

生成报告时：
1. 从 `ak.stock_zh_a_spot()` 抓取昨日涨停股票
2. 存入 `yesterday_limit_ups`
3. 今日报告中读取昨日涨停股，计算今日平均涨跌幅，存入 `yesterday_limit_ups_performance`
