## 一、数据层：AKShare 聚合接口

### 目标
用 `akshare` 作为统一数据源，替代当前手拼的腾讯财经接口，提高稳定性。

### 现有问题
- 全市场股票列表：EastMoney API，可能限流
- 批量行情：腾讯财经接口，不稳定
- 新浪接口：已被封

### 优化方案

| 场景 | 当前 | 优化后 |
|------|------|--------|
| 全市场股票列表 | EastMoney API | `akshare.stock_zh_a_spot()` |
| 批量行情 | 腾讯财经 | `akshare` 统一接口，自动降级 |
| 指数行情 | 分开调多个 | `akshare.stock_zh_index_daily()` |
| 板块数据 | 同花顺 THS | `akshare` 统一封装 |

### 均线多头候选池
1. 用 `akshare.stock_zh_a_daily()` 取全市场日线数据（复权）
2. 计算 MA5/MA10/MA20
3. 筛选条件：**MA5 > MA10 > MA20** 且 **收盘价 > MA20**
4. 候选池约 100-300 只（比 5000 只更精准）

## 二、报告提示词（散户友好版）

### 设计原则
- 结论前置
- 说人话，不堆专业术语
- 每部分有数字支撑，但解读要通俗

### 提示词结构

```
【市场总览】
用一句大白话总结今天行情，比如"今天A股普涨，创业板表现最强"
参考：三大指数涨跌幅、成交额、涨跌家数

【今日亮点】
- 今天涨得最好的板块是什么？为什么？
- 哪些板块在轮动？
用大白话描述，避免"资金净流入"，说"钱都往哪流了"

【今天该注意什么】
给出 2-3 条通俗易懂的操作建议
结论前置，让散户知道今天该怎么做

【风险提醒】
用大白话提示风险，比如"今天涨得猛的别追"、"外围有波动"
```

### 沉淀位置
`backend/app/prompts/report_prompt.py`

## 三、推荐逻辑（均线候选 + AI 精选）

### 筛选流程

```
第一步：获取全市场日线数据
↓（通过 akshare）
第二步：筛选均线多头（MA5>MA10>MA20，收盘>所有均线）
↓（候选池约100-300只）
第三步：量价过滤（成交量放大、涨幅3%-8%）
↓（候选池约50只）
第四步：AI 从 50 只里选 5 只
↓（输出推荐股票 + 理由）
第五步：存入数据库
```

### 候选池大小控制
- 原始候选：均线多头，约 100-300 只
- AI 筛选前：量价过滤后，约 50 只
- 最终输出：5 只

### 输出格式
```json
{
  "code": "000001",
  "name": "平安银行",
  "price": 12.34,
  "reason": "均线多头排列，成交量放大，短线有机会"
}
```

### 沉淀位置
`backend/app/prompts/recommend_prompt.py`

## 四、触发体验（一键生成）

### 执行顺序
1. 抓取今日行情（指数 + 板块）→ 更新数据库
2. 生成市场报告（AI）→ 存入 `market_reports` 表
3. 筛选均线多头 → AI 选 5 只 → 存入 `recommendations` 表
4. 更新所有推荐股现价和收益率

### 前端交互
- 一个「一键生成」按钮
- 显示当前步骤和进度（step indicator）
- 每步完成后有状态提示
- 全部完成后可切换到报告/推荐 Tab 查看结果

### 时间估算
- 行情抓取：10-20 秒
- 市场报告生成：15-30 秒
- 候选筛选 + 推荐生成：30-60 秒（主要瓶颈）
- 现价更新：10-20 秒
- 合计约 2-3 分钟

## 七、已知风险

1. **全市场日线数据量大**：akshare 抓 5000 只日线可能需要 30-60 秒，需要加缓存
2. **AI 生成时间**：推荐生成约 60 秒，前端需要长连接或轮询
3. **市场节假日**：需要判断是否为交易日，非交易日不生成
