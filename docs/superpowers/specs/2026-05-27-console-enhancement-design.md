# 控制台页面增强设计文档

## 背景

当前控制台页面（SettingsPage）只有生成报告、生成推荐、更新现价、定时任务配置等功能。用户希望添加数据管理功能，包括删除和编辑报告、删除和编辑推荐股票。

## 目标

### 报告管理（CRUD）
1. **读取报告**：查看指定日期的报告内容
2. **更新报告**：修改 AI 生成的报告文本内容
3. **删除报告**：删除指定日期的市场报告
4. 注：不需要手动创建报告（已有 AI 自动生成）

### 推荐管理（完整 CRUD）
1. **创建推荐**：手动添加新的推荐股票
2. **读取推荐**：查看指定日期的推荐列表
3. **更新推荐**：修改现有推荐的股票信息
4. **删除推荐**：删除指定日期的推荐记录

## 非目标

- 不做批量删除/编辑
- 不做导入/导出功能
- 不做操作日志

### 数据流

**删除报告**：
1. 用户选择日期 → 点击删除按钮
2. 弹出确认框
3. 确认后调用 `DELETE /api/report/daily?date=YYYY-MM-DD`
4. 后端删除 `market_reports` 表中对应记录
5. 返回成功/失败消息

**编辑报告**：
1. 用户选择日期 → 点击加载按钮
2. 调用 `GET /api/report/daily?date=YYYY-MM-DD` 获取报告内容
3. 显示报告内容（AI 报告文本）
4. 用户点击编辑 → 文本区域变成可编辑状态
5. 修改内容 → 点击保存
6. 调用 `PUT /api/report/daily?date=YYYY-MM-DD` 更新报告
7. 返回成功/失败消息

**删除推荐**：
1. 用户选择日期 → 点击删除按钮
2. 弹出确认框
3. 确认后调用 `DELETE /api/recommend/daily?date=YYYY-MM-DD`
4. 后端删除 `recommendations` 表中对应记录
5. 返回成功/失败消息

**编辑推荐**：
1. 用户选择日期 → 点击加载按钮
2. 调用 `GET /api/recommend/daily?date=YYYY-MM-DD` 获取推荐列表
3. 显示推荐股票列表
4. 用户点击编辑 → 每只股票变成可编辑状态
5. 修改股票代码、名称、推荐理由
6. 可以点击「添加股票」或「删除股票」
7. 点击保存
8. 调用 `PUT /api/recommend/daily?date=YYYY-MM-DD` 更新推荐
9. 返回成功/失败消息

## 数据模型

### 使用的现有字段

```sql
-- market_reports 表
report_date      DATE, UNIQUE    -- 报告日期
ai_report        TEXT            -- AI 分析报告正文

-- recommendations 表
recommend_date   DATE            -- 推荐日期
stock_code       VARCHAR(10)     -- 股票代码
stock_name       VARCHAR(50)     -- 股票名称
recommend_price  DECIMAL(10,3)   -- 推荐价格
reason           TEXT            -- 推荐理由
```

### 新增请求/响应模型

```python
# 删除请求
class DeleteRequest(BaseModel):
    date: date

# 更新报告请求
class UpdateReportRequest(BaseModel):
    ai_report: str

# 更新推荐请求
class UpdateRecommendRequest(BaseModel):
    stocks: List[RecommendStock]

class RecommendStock(BaseModel):
    stock_code: str
    stock_name: str
    recommend_price: float
    reason: str
```

## API 设计

### 报告管理

#### 1. 获取报告详情

```
GET /api/report/daily?date=2025-05-27
```

**响应**：
```json
{
  "success": true,
  "data": {
    "report_date": "2025-05-27",
    "ai_report": "报告内容...",
    "market_summary": "市场概况...",
    "index_data": "指数数据JSON...",
    "hot_sectors": "热门板块JSON..."
  }
}
```

#### 2. 更新报告

```
PUT /api/report/daily?date=2025-05-27
```

**请求体**：
```json
{
  "ai_report": "修改后的报告内容...",
  "market_summary": "修改后的市场概况..."
}
```

**响应**：
```json
{
  "success": true,
  "message": "报告更新成功"
}
```

#### 3. 删除报告

```
DELETE /api/report/daily?date=2025-05-27
```

**响应**：
```json
{
  "success": true,
  "message": "报告删除成功"
}
```

```json
{
```

```
DELETE /api/recommend/{recommend_id}
```

**响应**：
```json
{
  "success": true,
  "message": "推荐删除成功"
```

## 风险与应对

| 风险 | 影响 | 应对措施 |
|-----|------|---------|
| 误删除数据 | 数据丢失 | 添加确认框，二次确认 |
| 编辑冲突 | 数据覆盖 | 使用乐观锁或版本号 |
| 并发操作 | 数据不一致 | 添加操作锁 |

## 成功指标

1. **功能完整性**：4个管理功能全部实现
2. **用户体验**：操作简单直观
3. **数据安全**：误删除有确认保护
4. **性能**：操作响应时间 < 2秒
