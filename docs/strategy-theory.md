# AlphaPick 量化选股理论依据

> 本文档回答一个根本问题：**为什么 AlphaPick 选的股票，未来 3-7 个交易日更可能上涨？**
> 没有理论依据的选股是拍脑袋；本文档确立理论 → 因子 → 验证的完整逻辑链。
> 关联规格：`docs/specs/recommendation.md`（当前策略实现）、`docs/specs/tracking.md`（收益验证）

## 1. 核心命题

> **A 股市场散户主导、定价低效，短线（1-4 周）存在显著动量效应：过去强势的股票，未来短期继续强势。**
> AlphaPick 通过量化识别"强势延续"的股票，赚取**动量超额收益（Alpha）**，并以反转风险控制回撤。

## 2. 市场前提：A 股为什么定价低效

动量效应在有效市场中不应存在（价格已反映全部信息）。A 股动量显著的前提是**定价低效**：

| 市场特征 | 事实 | 对定价的影响 |
|---|---|---|
| 投资者结构 | 散户贡献约 80% 交易量 | 情绪驱动，非理性定价 |
| 信息传播 | 利好逐步发酵，非一步到位 | 价格调整缓慢 → 动量延续 |
| 行为偏差 | 羊群效应、处置效应、锚定 | 趋势自我强化，强者恒强 |
| 制度约束 | T+1、涨跌停（±10%/20%） | 抛压滞后、封板锁筹 → 惯性延续 |

**结论**：A 股是一个"半强式无效"市场，信息与情绪的扩散过程就是股价的动量过程。这是 AlphaPick 全部选股逻辑的市场前提。

## 3. 理论机制：为什么"强者恒强"

学术与实证支持三条机制（对应三个核心因子）：

### 3.1 短线动量效应（Momentum）→ 因子：今日涨幅

- **学术依据**：Jegadeesh & Titman (1993) 动量异象；A 股实证（周收益率动量）显示 1-4 周动量显著强于美股
- **机制**：散户"反应不足 + 羊群跟进"——上涨吸引注意力，注意力带来买盘，买盘推动继续上涨
- **失效条件**：连续暴涨末端（涨幅 ≥8%），动量耗尽转为反转（见 §4）

### 3.2 趋势延续（Trend）→ 因子：连续上涨天数

- **机制**：连续多日上涨 = 资金持续流入的信号，趋势惯性来自"持仓者惜售（处置效应） + 观望者进场"
- **A 股特色**：连板/连阳是市场情绪的温度计，连涨天数与"强者恒强"高度相关
- **失效条件**：连涨 ≥5 天后，情绪透支，炸板/回落概率上升

### 3.3 活跃度与流动性（Liquidity）→ 因子：换手率

- **机制**：换手率反映关注度与交易活跃度；适度活跃的股票有"资金接力"的土壤
- **理论**：流动性溢价——活跃股冲击成本低，机构与大资金偏好
- **A 股特色**：题材股的活跃度 = 注意力经济，量价齐升是资金共识的体现

### 3.4 注意力溢价（A 股特有，辅助因子）

- 涨停、连板、龙虎榜天然吸引全市场注意力 → 资金虹吸
- AlphaPick 的涨停板数据（`docs/specs/limit-up.md`）可作为动量因子的增强信号（后续迭代）

## 4. 反面保护：短期反转风险（Risk Penalty）

动量策略的最大敌人是**动量崩溃**：情绪过度后价格反转。理论依据：

- **实证**：A 股连板股炸板率高，追高 8%+ 的股票 3-5 日内回落概率显著上升
- **行为解释**：羊群买盘在涨停末端耗尽（接力资金枯竭），获利盘兑现
- **对策**：当前策略对 涨幅≥8% / 换手≥18% / 连涨≥5天 施加风险惩罚（-10% 权重）

## 5. 因子 → 理论映射表（当前策略 v2）

| 权重 | 因子 | 理论机制 | 可观测信号 |
|---|---|---|---|
| 30% | momentum | 短线动量（信息扩散+羊群） | 今日涨幅 |
| 25% | trend | 趋势延续（资金持续流入） | 连续上涨天数 |
| 20% | liquidity | 活跃度/流动性溢价 | 换手率 |
| 15% | source_quality | 工程可信度（非市场理论） | 数据源 |
| -10% | risk_penalty | 反转风险（动量崩溃保护） | 涨幅/换手/连涨超阈值 |

## 6. 三大可验证假设（拒绝拍脑袋）

理论必须可证伪。AlphaPick 的选股逻辑收敛为三个假设，**全部可以用现有历史数据验证**：

| 假设 | 内容 | 验证指标 |
|---|---|---|
| H1 | 今日涨幅高的股票，未来 3/5/7 日收益显著为正 | 动量因子 IC（秩相关），\|IC\| ≥ 0.03 有效 |
| H2 | 连涨天数长的股票，动量持续性更强 | trend 因子分层单调性 |
| H3 | 换手率存在最优区间（活跃但不过热），收益最好 | liquidity 因子分层单调性（倒 U 型） |

## 7. 验证方法（回测协议）

```
1. 因子 IC 检验     每个因子与未来 3/5/7 日收益的 Spearman 秩相关（滚动月度 IC 均值）
2. 分层回测         按因子值分 5 组（Q1 最优 → Q5 最差），检验收益单调性
3. 组合回测         策略组合（Top5）收益 vs 基准（沪深300 / 全市场等权），计算超额收益与夏普
4. 样本外验证       前 6 个月数据定权重 → 后 6 个月滚动验证（防止过拟合）
5. 胜率与回撤       策略胜率（3/5/7 日 >0 比例）、最大回撤、炸板率
```

**判定标准**：仅当 H1-H3 通过验证（IC 显著 + 分层单调）且组合回测跑赢基准时，策略因子与权重才可上线；否则调整理论假设。

## 8. 策略迭代闭环（理论 → 数据 → 优化）

```
理论假设（本文档）
  → 因子定义（specs/recommendation.md）
  → 每日选股上线（回测验证通过后）
  → 收益跟踪（specs/tracking.md 1/3/5/7 日）
  → 统计复盘（胜率/IC/归因）
  → 因子衰减检测 → 修订理论/权重
  → 回到起点
```

AlphaPick 不做"黑盒玄学选股"，每一步选股决策都可以追溯到本文档的理论机制。

## 9. 当前局限与后续研究方向

| 局限 | 方向 |

| 因子仅 5 个，未覆盖估值/质量/资金流 | 扩展：PE/PB 价值因子、北向资金流因子、龙虎榜因子 |
